# stones
Our duty to continue the work without attachment to the fruits

Distilled public records of engineering work on the GlobalGrid2050 project: measurements, decisions,
and defects found in our own work, each with the artefact that settles it.

- [INDEX.md](INDEX.md) lists every record with its digest.
- [POLICY.md](POLICY.md) states what is published, what is excluded, and how records are keyed.

Records are distilled into neutral professional language from private working notes, which are not
published. Each record carries the digest of the note it came from, so the two can be matched later
without the note ever being disclosed.

Every number here came from a command that can fail. No warranty is given.
